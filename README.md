# Splashes — Project 1

A responsive children's swimming lesson website created for the WEB801 Project 1 requirements.

## Pages
- Home
- Lessons
- Schedule
- About
- Contact

## Requirements covered
- 5 responsive HTML pages
- HTML headings, paragraphs, lists, links and images/icons
- HTML comments
- HTML table
- HTML form with submit button
- CSS3 styling
- JavaScript interactions
- jQuery
- Ajax schedule loading
- Bootstrap 4 components/classes
- Vue component example in `js/vue-app.js`
- GitHub-ready structure

## Run in VS Code
1. Extract/open this folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. Navigate through all five pages.
